# 编辑许可与动作协议

## 允许的变换

- 删除不带信息的套话和重复;
- 在不改变逻辑关系时调整句序、段序;
- 压缩、合并或拆分句子;
- 用输入已有的具体信息替换抽象判断;
- 修正翻译腔、语体错配和标点功能;
- 保留并强化原文已有的判断、犹豫、限制与圈内说法。

## 禁止的变换

- 新增输入中没有的数字、经历、来源、引语、人物动作、产品能力或因果结论;
- 为了「像人」编第一人称现场、情绪或口头禅;
- 把不确定信息写成确定事实;
- 为破对称而破坏 brief、法律结构、正式枚举或真实业务分层;
- 把作者笔调洗成统一的短句、金句或口语。

## 编辑顺序

1. 结构:删空开场 / 空收束,处理机械路标和重复结构。
2. 词汇:结合语体处理 B/D/E/J,不按裸字符串替换;有通行术语的概念还原成通行说法,不保留自造词(判定与放行边界见 `patterns/banned-words.md` B 组「自造术语」)。
3. 句法:动词强化、抽象落具体、中文语序归位。
4. 节奏:只修机械均质,不套固定长短句公式。
5. 标点与载体格式:最后处理。

需要外部新增事实时,先退出 transform 流程,由明确授权的研究流程提供来源和引用;核实后的材料并入输入后再编辑。`scripts/check-fact-integrity.py --allow-added` 只用于这类独立研究结果审计,不用于普通改写放行。

事实脚本的 BEFORE / AFTER 应只包含待比较正文。若输出文件同时含报告与终稿,用 `--after-section 终稿` 只选择 Markdown 的「终稿」章节;列表序号和标题编号按排版处理,不算新增事实。
