# Lens Profile

从项目维护者的真实手动改稿中提炼。只在用户明确指定 `lens` 或当前工作区明确绑定此 Profile 时启用,不得作为公开安装的默认笔调。

## 禁用与克制

- 避免「集中火力、临门一脚、打透、打爆、挑大梁、主战场、卡位、稳住盘面、冲刺」等装饰性江湖气。
- 小标题先写主体、任务或结论,不以否定句制造洞察感。
- 「不是 X,而是 Y」默认克制;X/Y 是可量化、不可互换的策略选项时单次可用,同段扎堆时改成肯定陈述。
- 自造比喻词个人层从严:「效率线」「双引擎」「半案」这类词一律还原成标准说法;量化标准直接写「标准 / 阈值」,不造「××线」式说法(通用判定见 `patterns/banned-words.md` B 组「自造术语」,本条是在其上收紧的个人雷区)。

## 正面习惯

- 数据带口径和来源;无法核对写「待确认」。
- 小标题写成结论,不用空名词标题。
- 中文引号用「」,嵌套用『』;汉字与英文 / 数字间留一个半角空格。
- 结论前置,因果与边界外显。
- 乙方 deck 的战略角色、KFS、节点日历、预算和人群分层有业务功能时保留。
- 路径递进可用「→」;编号只留给真正需要编号的清单。
- 人群描写用行为和场景承载情绪,不直接替人群断言心理状态。
- 章节收尾落在动作、责任或待确认项,不做空升华。

## 笔调参数

| 维度 | 倾向 |
|------|------|
| 句长 | 判断句短,数据与逻辑句可展开;长短交替 |
| 连接 | 因果外显,少用机械路标词 |
| 用词 | 具体动词驱动;行业术语与抒情句分区 |
| 节奏 | 短段砸判断;数据 / 逻辑段中等长度 |
| 人称 | 按任务决定,不把「她们 / 我们」推广成通用规则 |
