# 风格锚点(few-shot)

> 1.0 起本文件只提供锚点提取方法与空模板,不再作为公开安装的默认个人笔调。维护者的脱敏参数已迁到 `profiles/lens.md`;真实范文应放在安装目录外的本地 Profile。

经验结论:**给范文比堆规则更有效**。在阶段 3 注入人味时,与其只靠禁用词表约束,不如塞 1–2 段目标风格的真实文字做 few-shot,让输出对齐一个具体的人的笔调,而不是对齐一个通用「人类」。

这一点被 shuorenhua 的 `.writer/` 参考文章库和 OUBIGFA 的 good-writing 模式共同验证。

---

## 怎么用

1. 在安装目录外的本地 Profile 里放入你自己的真文段落,或你想模仿的目标范文;按授权范围保存,不要把客户真稿误提交到公开仓库。
2. 调用本 Skill 时明确指定 Profile;阶段 3 只提取用词、句式与节奏倾向。
3. 不同渠道可以存不同锚点。没有锚点时,退回 `channel-presets.md` 的渠道默认语体。

**注意**:锚点只影响「笔调 / 风格」,不影响事实。锚点里的具体信息不会被搬进你的稿子(那会违反事实原则)。

## 外部 Profile 锚点模板

### 锚点 · 通用 / 默认
> (在外部本地 Profile 中填写 1–2 段你最满意、最像你本人的文字)

### 锚点 · 对外提案 / 客户方案
> (在外部本地 Profile 中填写一段过往的高质量提案文字)

### 锚点 · 长报道 / 特稿
> (在外部本地 Profile 中填写一段你欣赏的特稿 / 你自己的报道段落)

### 锚点 · 公众号
> (在外部本地 Profile 中填写一段目标公众号风格文字)

### 锚点 · 主播 / 口播
> (在外部本地 Profile 中填写 1–2 段已经播出或确认满意的逐字稿片段)

---

## 提取风格的维度(供阶段 3 参考)

读锚点时关注这些,而不是照抄内容:
- 句子的平均长度与长短句落差
- 常用的连接方式(显式连词 vs 意合)
- 标点习惯(逗号密度、是否用破折号、问句频率)
- 用词偏好(书面 vs 口语、成语密度、是否爱用具体名词)
- 段落节奏(是否爱用短段、是否有停顿与留白)
- 人称与语气(第一人称介入度、克制 vs 热情)
- 口播特征(承重句是否短准、连接组织是否自然、软垫词 / 反问 / 自我修正是否承担听觉功能)
