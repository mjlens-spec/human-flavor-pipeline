# 交付格式

## Detect

```text
【门检】必要性、置信度、载体 / 受众 / 语体 / 笔调
【评分】AI 味等级与分数、证据 cluster;人味总分与最低维度
【Profile / Pack】本次实际启用项
【热区】段号、真实引用、主导模式
【风险】事实 / 来源 / 格式 / 载体
```

不改正文。

## Review

包含 Detect,再给最值得改的 3–8 处局部建议:

```text
【Before】原文真实引用
【After】局部改法
【理由】解决什么问题,事实是否变化
```

不输出整篇替换稿。正式文档默认先走 Review。

## Full

输出终稿,再附:

```text
【评分】改前 → 改后,附证据
【保护区】数字 / 实体 / 引语核对
【新增事实】普通改写必须为「无」
【主要改动】结构 / 词汇 / 句法 / 格式
【保留项】原文判断、限制、笔调与合法专业结构
【残留项】未改处及原因
```

快速聊天可压成一行,但不得省略事实漂移警告。
